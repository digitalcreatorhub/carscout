# CarScout

Проверка цены автомобиля для покупателя в Латвии. Вставляете ссылку на объявление (ss.com, AutoScout24 и др.), получаете вердикт по реальному рынку: с чем сравнивали, сколько объявлений, типичная цена и диапазон, ближайшие аналоги со ссылками, калькулятор ввоза, сообщение продавцу на его языке, историю по VIN и сколько дней такие машины висят на ss.lv.

Сайт: https://digitalcreatorhub.github.io/carscout/ (устанавливается как приложение, PWA). Сервер: https://carscout.pmax70095.workers.dev

Правила для тех, кто меняет код (логика вердиктов, бесплатные сервисы, проверки), лежат в [CLAUDE.md](CLAUDE.md). Этот файл описывает, из чего всё состоит и как запускается.

## Из чего состоит

| Часть | Где | Что делает |
|---|---|---|
| Страница | `index.html`, `sw.js`, `manifest.webmanifest` | Весь интерфейс в одном файле, работает в браузере. Лежит на GitHub Pages. Избранное и сохранённые поиски хранятся в браузере. |
| Сервер | `worker/worker.js`, `wrangler.toml` | Cloudflare Worker: читает объявления и выдачу сайтов на стороне сервера, считает рынок, хранит память в базе D1, по cron каждые 5 минут отвечает в Telegram, шлёт уведомления и проверяет, ушли ли объявления. |
| Память | база D1 `carscout-memory` | История цен и пробега объявлений, срок продажи, сохранённые поиски, подписки на уведомления. Старые строки удаляются раз в сутки. |
| Нейросеть | Workers AI (привязка `AI`) | Выбирает поколение модели по 2-4 фото, когда год объявления совпадает с первым годом нового кузова. Без привязки приложение работает так же, просто не спрашивает. |
| Проверки и оповещения | `tools/`, `.github/workflows/` | Ежедневные и офлайн-проверки, обход рынка, Telegram и телефонные уведомления. Работают в GitHub Actions. |

## Откуда берутся данные

- **ss.com / ss.lv**: основной рынок Латвии. Читается сервером (страницы объявлений и выдача, RU/LV/EN).
- **AutoScout24** (Германия, Бельгия, Нидерланды, Франция) и **autoportaal.ee**: читаются сервером.
- **autoplius, autogidas, auto24**: отдают сайт только браузеру. Добавляются через закладку CarScout: пользователь сам открывает страницу в своём браузере и нажимает закладку, сервер только разбирает присланный HTML (`POST /api/import`), ничего не сохраняет и сам на эти сайты не ходит. Объявления остаются в браузере пользователя на 3 дня.
- Копарт, IAAI и VIN-сервисы: история по VIN (`/api/vinhist`).
- Любая другая выдача: «Литва, Эстония и другие сайты», вставить адрес поиска.
- Скриншот объявления: текст распознаётся прямо в браузере (Tesseract), поля можно поправить.

Цены на сайтах это цены предложений, а не сделок. «Ушло с сайта» не обязательно означает «продано».

## Адреса сервера

Все ответы в формате JSON. Корневой адрес `/` показывает статус и версию.

| Адрес | Что делает |
|---|---|
| `/api/listing` | Факты из одной страницы объявления |
| `/api/comps` | Реальные аналоги с ss.com, AutoScout24 и autoportaal. Для ss.com с `yfilter=1&yfrom=&yto=` (поиск выгодных машин) читаются только нужные годы через фильтр самого сайта (сначала открывается категория ради cookie, потом POST на `.../filter/`, до 8 страниц; в ответе `yearsOnly` и причина отката `yearsWhy`); при любом сомнении читаются первые страницы категории, как раньше |
| `/api/search` | Любая вставленная страница выдачи |
| `/api/import` (POST) | Объявления со страницы, присланной закладкой |
| `/api/seller` | Другие объявления продавца |
| `/api/memory`, `/api/trend` | История цен и индекс цен из памяти |
| `/api/vinhist` | История по VIN |
| `/api/img` | Прокси для фото |
| `/api/photogen` | Поколение модели по фото (нейросеть) |
| `/api/watch` (GET и POST) | Сохранённые поиски |
| `/api/push/key`, `/api/push/sub`, `/api/push/inbox`, `/api/push/finds`, `/api/push/tick` | Уведомления на телефон о находках по сохранённым поискам |
| `/api/alive/tick` | Проверка, ушли ли объявления (срок продажи) |
| `/api/tg/status`, `/api/tg/subs`, `/api/tg/link` | Привязка Telegram-бота |
| `/api/debug` | Что сервер реально получил от сайта (когда разбор сломался) |

## Проверки

| Проверка | Когда | Что проверяет |
|---|---|---|
| `tools/selfcheck.mjs` | каждый день, GitHub Actions `selfcheck.yml` | Реальные объявления через живой сервер: читаются ли все поля на ss.com, аналоги, VIN, версия сайта. При ошибке открывает issue «Ежедневная проверка CarScout нашла ошибки», при успехе закрывает. |
| `tools/logiccheck.mjs` | каждый день, там же | Фиксированные сценарии в живом приложении (браузер Playwright): правильный рынок, «подозрительно дёшево» только при достаточном числе объявлений и т. д. |
| `tools/lifecheck.mjs`, `ratecheck.mjs`, `dbcheck.mjs`, `parsercheck.mjs`, `photocheck.mjs`, `readmecheck.mjs` | при каждом push и pull request, `lifecheck.yml` | Офлайн, без сети: срок продажи, лимиты запросов, ночная очистка базы, читатели сайтов, поколение по фото, соответствие этого README коду. |
| `tools/crawl.mjs` | каждый день, `market.yml` | Обход популярных моделей, чтобы память и индекс цен заполнялись и для моделей, которые сегодня никто не проверял. |
| `tools/notify.mjs`, `tools/pushtick.mjs` | каждые 15 минут, `notify.yml` | Telegram-оповещения (снижение цены, объявление пропало, новое ниже рынка) и телефонные уведомления. |

Запуск офлайн-проверок: `node --no-warnings tools/<имя>.mjs` (Node 22). `readmecheck` падает, если в `worker/worker.js` появился адрес `/api/...`, а в этом файле его нет, или если в `tools/` и `.github/workflows/` есть файл, о котором здесь не написано. Поэтому при добавлении адреса, проверки или workflow обновляйте этот README.

## Запуск с нуля (бесплатно)

1. **Cloudflare**: Workers & Pages → Create → Import a repository, выбрать этот репозиторий. Cloudflare читает `wrangler.toml` и после каждого слияния в `main` выкладывает сервер заново.
2. **База**: Storage & Databases → D1 → создать базу `carscout-memory`, её `database_id` вписать в `wrangler.toml`. Таблицы сервер создаёт сам.
3. **Переменная** `ALLOW_ORIGIN` (в `wrangler.toml`): адрес страницы, `https://digitalcreatorhub.github.io`. Тогда сервером из браузера пользуется только эта страница.
4. **Страница**: GitHub Pages, ветка `main`, корень. Адрес сервера вписан в `index.html` в строке `var API_DEFAULT=...`; его же можно задать на устройстве кнопкой «Сервер».
5. **Telegram** (по желанию): токен бота в секрете `TG_TOKEN` репозитория GitHub (для `notify.yml`) и в секретах сервера Cloudflare (для ответа на /start и /stop).

## Бесплатные лимиты

Данные Cloudflare на 22.10.2026, актуальные цифры: [Workers](https://developers.cloudflare.com/workers/platform/limits), [D1](https://developers.cloudflare.com/d1/platform/pricing/).

- Workers Free: 100 000 запросов в сутки, 10 мс процессорного времени на запрос, 50 подзапросов на запрос.
- D1 Free: 5 млн прочитанных и 100 000 записанных строк в сутки, 5 ГБ.
- Платный Workers Paid (от $5 в месяц) снимает дневные лимиты запросов, базы и поднимает процессорное время.

Сервер сам ограничивает запросы с одного адреса (`RL_LIMIT` в `worker.js`) и чистит базу раз в сутки. Менять эти числа можно только вместе с `ratecheck` и `dbcheck`.

## Важно знать

- **Условия сайтов.** Автоматическое чтение страниц может нарушать условия сайта. Для AutoScout24 в общих условиях есть прямой запрет автоматических запросов скриптами и сбора данных в свою базу. Правила ss.com прямого запрета не содержат, а его `robots.txt` закрывает только служебные разделы. Сервер представляется обычным браузером (`User-Agent`), капчи и защиту от ботов не обходит. Для личного использования риск небольшой, для публичного сервиса нужно отдельное решение: разрешение сайтов, официальный доступ (у ss.com есть раздел «Сотрудничество») или отказ от чтения этих сайтов сервером.
- Если сайт перестал читаться: откройте `<адрес сервера>/api/debug?url=<ссылка>` и пришлите результат. Вёрстка сайтов меняется, а AutoScout24 и mobile.de часто блокируют серверы (в таблице строка «сайт не отдал страницу серверу»).
- Условие «только бесплатные сервисы» действует для всего: новые функции не должны требовать платных ключей.
