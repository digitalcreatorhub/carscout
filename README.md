# CarScout Live: инструкция по запуску (всё бесплатно, около 15 минут)

Состоит из двух частей:
- **worker.js** — маленький сервер на Cloudflare Workers. Он открывает объявления и выдачу на ss.com и AutoScout24 и отдаёт страницы чистые данные.
- **index.html** — сама страница. Лежит на GitHub Pages, как ваш Laiks.

## 1. Сервер (Cloudflare)
1. Зарегистрируйтесь на cloudflare.com (бесплатный тариф, карта не нужна).
2. Меню **Workers & Pages** → **Create** → **Create Worker** → имя `carscout` → **Deploy**.
3. Нажмите **Edit code**, удалите весь код, вставьте содержимое `worker/worker.js`, нажмите **Deploy**.
4. Скопируйте адрес вида `https://carscout.ВАШ-ПОДДОМЕН.workers.dev` и откройте его в браузере. Должно появиться `{"ok":true,"name":"CarScout Live worker",...}`.
5. (Рекомендуется) **Settings → Variables and Secrets → Add**: имя `ALLOW_ORIGIN`, значение `https://digitalcreatorhub.github.io` (адрес вашего GitHub Pages). Тогда сервером смогут пользоваться только вы.

## 2. Страница (GitHub Pages)
1. На github.com создайте новый публичный репозиторий `carscout`.
2. **Add file → Upload files** → загрузите `index.html` → **Commit**.
3. **Settings → Pages → Deploy from a branch → main / root → Save**.
4. Через минуту страница откроется по адресу `https://ВАШ-ЛОГИН.github.io/carscout/`.

## 3. Соединить
Откройте страницу → кнопка **Сервер** → вставьте адрес воркера → **Сохранить и проверить**. Зелёная точка значит, что всё работает. На телефоне то же самое, адрес запоминается в браузере.
Чтобы адрес не вводить на каждом устройстве, впишите его в `index.html` в строку `var API_DEFAULT='';` перед загрузкой на GitHub.

## Как пользоваться
- Вставьте ссылку на объявление ss.com, AutoScout24 и др. и нажмите «Проверить автомобиль».
- Сервер прочитает объявление, соберёт реальные аналоги (ss.com для Латвии, AutoScout24 для Германии) и покажет вердикт, график, ближайшие объявления со ссылками и калькулятор ввоза.
- Литва, Эстония и другие сайты: откройте поиск на сайте, задайте фильтры, скопируйте адрес выдачи и вставьте в блок «Литва, Эстония и другие сайты».
- Ссылка не читается: загрузите скриншот. Текст распознаётся в браузере (Tesseract), потом поля можно поправить вручную.

## Важно знать
- **Это не проверено на живых сайтах.** Код тестировался на модельных страницах, потому что с моей стороны эти сайты недоступны. Вёрстка сайтов меняется, и AutoScout24 и mobile.de часто блокируют запросы с серверов (тогда в таблице будет строка «сайт не отдал страницу серверу»).
- Если сайт не читается: откройте `АДРЕС-ВОРКЕРА/api/debug?url=ССЫЛКА` (ссылку желательно закодировать) и пришлите мне результат, я поправлю разбор.
- Цены на сайтах — это цены предложений, а не сделок.
- Условия сайтов могут запрещать автоматический сбор данных. Используйте для личных проверок, не делайте общедоступным сервисом.
- Бесплатный лимит Cloudflare: 100 000 запросов в сутки, одной проверке хватает нескольких.
